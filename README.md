# NOCTURNE — Web Horror Prototype

Статическая 3D horror-игра для GitHub Pages. Сервер, Node.js и сборка не нужны.

## Что уже есть

- 3D-особняк с туманом и слабым освещением;
- FPS-управление: WASD + мышь;
- бег на Shift, ограниченная стамина и восстановление;
- процедурные звуки шагов, дверей, ключей и предметов;
- пауза на Esc и автоматическая пауза при потере фокуса;
- монстр с патрулированием, остановками и плавным разворотом;
- поле зрения монстра, погоня и движение к последней точке, где он видел игрока;
- надпись «БЕГИ!!!» во время обнаружения и 2 секунды после потери прямой видимости;
- реплика монстра через Speech Synthesis;
- поражение при касании и кнопка «Заново»;
- взаимодействие ЛКМ по центру экрана и с ограниченной дистанцией;
- фонарик на F, расход заряда и батарейки;
- руны и счётчик рун;
- зрение монстра на E за 1 руну, длительность 5 секунд, Q — выйти раньше;
- ключи A1/B1, при этом одновременно можно нести только один ключ;
- двери: обычные и запертые конкретным ключом;
- монстр не открывает двери, но проходит через уже открытые;
- выход из особняка — достаточно дойти до зелёной выходной зоны;
- HUD стамины, заряда, рун и текущего ключа.

## Управление

- `WASD` — движение
- `Shift` — бег
- `мышь` — камера
- `ЛКМ` — взаимодействие
- `F` — фонарик
- `E` — зрение монстра (нужна руна)
- `Q` — выйти из зрения монстра раньше
- `Esc` — пауза

## Как загрузить на GitHub Pages

1. Создай обычный публичный репозиторий GitHub.
2. Загрузи в корень репозитория:
   - `index.html`
   - `style.css`
   - `game.js`
   - `README.md`
3. Открой `Settings` -> `Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. Branch: `main`, Folder: `/ (root)`.
6. Сохрани. После публикации GitHub покажет адрес сайта.

## Важно

Three.js подключается из jsDelivr CDN. Поэтому при первом запуске игре нужен интернет. Для GitHub Pages это нормально.

Если нужен полностью автономный вариант без CDN, скачай `three.min.js` версии 0.160.1, положи рядом с `game.js` и в `index.html` замени:

```html
<script src="https://cdn.jsdelivr.net/npm/three@0.160.1/build/three.min.js"></script>
```

на:

```html
<script src="three.min.js"></script>
```

## Карта

Старт — южная часть особняка. Сначала найди ключ `A1`. После двери A1 можно найти ключ `B1`. Через B1 открывается доступ к северной части. Выход находится примерно в северо-восточной части карты.

## Где менять баланс

В `game.js`:

- скорость игрока: `player.walkSpeed`, `player.runSpeed`;
- расход стамины: строка `state.stamina - 23 * dt`;
- восстановление: `state.stamina + 16 * dt`;
- расход фонарика: `state.battery - 1.55 * dt`;
- скорость монстра в погоне: `moveMonsterAlongPath(dt, 4.15)`;
- память монстра: `now - monster.lastSeenAt <= 6.0`;
- дальность зрения: `if (dist > 12.5)`;
- угол зрения: `THREE.MathUtils.degToRad(46)` — это половина полного FOV;
- длительность зрения монстра игроком: `state.visionRemaining = 5`.
