# The Lost Girl — Web Horror

Статическая 3D веб-игра для GitHub Pages. Никакого сервера, npm или сборки не требуется.

## GitHub Pages

1. Создайте репозиторий.
2. Загрузите **всё содержимое проекта**, включая папку `assets`:
   - `index.html`
   - `style.css`
   - `game.js`
   - `assets/textures/*`
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**.
5. Branch: `main`, Folder: `/(root)`.
6. Сохраните настройки.

Three.js подключается через jsDelivr. Все игровые текстуры и остальные ресурсы проекта лежат локально в репозитории.

## Управление

- WASD — ходьба
- Shift — бег
- Мышь — камера
- ЛКМ — взаимодействие
- F — фонарик
- E — зрение Ноэлль (тратит 1 руну)
- Q — выйти из зрения Ноэлль раньше
- Esc — пауза

## Сюжетная цель

Крис возвращается в дом семьи Холидеев спустя 10 лет. Нужно:

1. Забрать увядшую розу.
2. Найти четыре записки с частями кода.
3. Найти и открыть сейф.
4. Забрать Терновое кольцо.
5. Забрать старую открытку.
6. Вернуться к входной двери и сбежать.

После поднятия розы появляется Ноэлль.

## Обновлённый особняк

Карта стала заметно больше и плотнее по наполнению. Это оригинальная хоррор-адаптация дома Холидеев, вдохновлённая его помещениями и праздничной стилистикой, а не буквальная копия карты Deltarune.

Внутри есть:

- большое фойе и центральная галерея;
- гостиная с тремя диванами, семейными портретами и ёлкой;
- кухня/столовая на шесть мест;
- старое белое пианино;
- подарочная кладовая;
- отдельная комната Ноэлль с холодной голубой отделкой;
- более тёмная комната Десс с музыкальными предметами;
- ванная и восточный салон;
- заваленная лестница, визуально продолжающая особняк вверх;
- шкафы, тумбы, столы, кровати, стулья, подарки, картины, окна, шторы, декор и мелкие предметы.

## Свет

- Фонарик исправлен и теперь использует более мощный SpotLight плюс небольшой ближний заполняющий свет.
- Луч фонаря следует за камерой в том же кадре, поэтому больше не отстаёт/не «пропадает».
- Расход батареи уменьшен **в 10 раз** по сравнению с предыдущей версией.
- Батарейки восстанавливают 48% заряда.
- По особняку стоят слабые тёплые и холодные лампы, некоторые мерцают.
- При пробуждении Ноэлль свет на короткое время почти гаснет.

## Зрение Ноэлль

Зрение монстра на `E` по-прежнему длится 5 секунд и расходует одну руну, но теперь:

- камера расположена перед лицом Ноэлль, а не внутри модели;
- поле зрения расширяется;
- туман временно становится намного слабее;
- повышается экспозиция сцены;
- добавляется специальный слабый supernatural-light возле камеры Ноэлль;
- изображение становится контрастнее и светлее;
- `Q` по-прежнему завершает просмотр раньше.

## Прятки и AI

- Ноэлль патрулирует комнаты и коридоры.
- При обнаружении преследует Криса и запоминает последнюю точку, где видела его.
- Закрытые двери блокируют путь и обзор; открытые двери позволяют пройти.
- За открытой дверью можно попытаться скрыться от линии зрения.
- В шкафах можно прятаться.
- Если Ноэлль видела, как Крис залез в шкаф, она идёт к нему, вытаскивает Криса наружу и после этого отступает в другую часть дома.
- При полноценной атаке запускается отдельный скример, затем экран поражения.

## Ассеты

В `assets/textures` находятся оригинальные локальные текстуры проекта: дерево, старая праздничная обивка стен, голубая комната Ноэлль, тёмная комната Десс, плитка, ковры, семейный портрет, шторы, грязное стекло, подарочная упаковка, бумага и загрязнённая штукатурка.

## Запуск локально

Для наиболее корректной проверки текстур лучше использовать простой локальный HTTP-сервер, например:

```bash
python -m http.server 8080
```

После этого открыть `http://localhost:8080`.
