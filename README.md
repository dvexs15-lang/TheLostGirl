# The Lost Girl — Web Horror

Статическая 3D веб-игра. Никакого сервера, npm или сборки не требуется.

## Запуск локально

Для обычного теста достаточно открыть `index.html` в браузере. Если браузер ограничивает некоторые функции при `file://`, можно использовать любой простой локальный HTTP-сервер.

## GitHub Pages

1. Создайте репозиторий.
2. Загрузите в корень репозитория:
   - `index.html`
   - `style.css`
   - `game.js`
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**.
5. Branch: `main`, Folder: `/(root)`.
6. Сохраните настройки.

Игра использует Three.js через jsDelivr CDN. Остальные модели, материалы, карта и звуки создаются прямо кодом.

## Управление

- WASD — ходьба
- Shift — бег
- Мышь — камера
- ЛКМ — взаимодействие
- F — фонарик
- E — зрение Ноэлль (тратит 1 руну)
- Q — выйти из зрения Ноэлль раньше
- Esc — пауза

## Сюжетная цель

Крис возвращается в дом семьи Холидеев спустя 10 лет. Нужно:

1. Забрать увядшую розу.
2. Найти четыре записки с частями кода.
3. Найти и открыть сейф.
4. Забрать Терновое кольцо.
5. Забрать старую открытку.
6. Вернуться к входной двери и сбежать.

После поднятия розы появляется Ноэлль.

## Реализовано

- процедурный 3D-дом семьи Холидеев;
- туман, слабый свет, мерцание ламп и фонарик с батареей;
- бег, стамина и звуки шагов;
- оригинальные лор-записки от лица Ноэлль;
- четыре части кода и сейф с вводом кода;
- отдельные предметы внутри открытого сейфа;
- руны и пятисекундное зрение Ноэлль;
- двери, которые физически вращаются и закрывают линию зрения;
- шкафы для пряток;
- если Ноэлль видела, как Крис залез в шкаф, она подходит, вытаскивает его и убегает в другую комнату;
- AI Ноэлль: патруль, остановки, погоня, последняя известная позиция, поиск и возвращение к патрулю;
- закрытые двери учитываются при построении пути Ноэлль;
- реплики Ноэлль через Speech Synthesis, если браузер его поддерживает;
- процедурные шаги, двери, окружение и скример через Web Audio;
- отдельный jumpscare и экран поражения;
- обязательная последовательность предметов перед побегом;
- автоматическая пауза при потере фокуса или захвата мыши.

## Важно

Лучше запускать на ПК/ноутбуке в Chrome, Edge или Firefox. Управление рассчитано на клавиатуру и мышь.
